# MiningVendors emoji pack dump

Source: https://t.me/addemoji/MiningVendors
Mirror: https://fullyst.com/emoji_set/MiningVendors

Telegram custom emoji set — public previews (100×100 webp thumbs) via fullyst.

## Layout

| path | content |
|------|---------|
| `webp/` | `00.webp` … original order from pack |
| `png/` | same, converted PNG |
| `by-id/` | files named by Telegram file id |
| `manifest.json` | urls + sizes |
| `alts.json` | emoji alt labels per index |
| `sheet.png` | contact sheet for browsing |

Full-resolution originals need Telegram Bot API `getStickerSet` + bot token (not available here).
Thumbs are enough to pick icons; re-export later if needed.

Map freely — nothing is wired into the app from this folder.
