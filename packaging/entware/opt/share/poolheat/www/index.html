r / repeat — repeat errors / repeats

Chip map · cache
disk cache · survives service restart

When enabled, after a successful LuCI poll the map is written to disk and reloaded on service start (stale until the next live poll). When off — cache file is deleted; only the current poll stays in RAM.

Module luci_proxy: reverse-proxy to the miner (host from “Whatsminer connection”). Externally — plain HTTP :8788, to miner — HTTPS; cookies Secure/HSTS are stripped. Default off. Do not expose :8788 on WAN — LAN / VPN / Cloud only.
